## 📌 Atividade de Locadora
### 📖 Sobre o projeto
Este projeto tem como objetivo **emular uma locadora dos anos 90**.
Ele foi desenvolvido para **uma atividade do projeto técnico em desenvolvimento web para a internet** .
O projeto consiste em páginas para simular as abas de filmes, simular o aluguel desses filmes, página sobre a locadora e uma para contato/avaliação
## 📄 Estrutura das páginas HTML
#### 🏠 index.html
É a página inicial do projeto, ela conecta todas as outras e todas as outras podem voltar para ela por meio de hyperlinks.
Foram utilizados: Títulos e subtítulos;  Hyperlinks "a" com estilização e com imagens (essas no arquivo imagens);
Tabelas para organizar os hyperlinks; Ícone no site; usa o estilo.css.
#### fale_conosco.html e alugar.html
são páginas que usam de tags de formulário para simular o aluguel de um ou mais filmes e para fazer um "reclame aqui", uiliza o estilo.css

As outras páginas em html com nome dos filmes são páginas para cada filme em cartaz para alugar, seguem usando praticamente as mesmas coisas do index,
a principal diferença é a utilização de hyperlinks para ir nos trailers do youtube de cada filme, uiliza o estilo.css.
#### sobre.html
é uma página que fala sobre a "história do site", ela utiliza o estilo copy.css porque o body modificado para os outros sites não são os mesmos dele.
 

## CSS🎨
O css inclui mudanças nas letras, links imagens, body e vários outros, há uma atenção especial na utilização do **hover** e em zoom in/ou,
seus arquivos são o **estilo.css** (quase todos) e **estilo copy.css** (sobre nos.html)
